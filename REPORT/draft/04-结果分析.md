# 四 结果分析

课程说明提出五个问题，逐个回答，末节记局限。

## 4.1 四种方法是否提高了 GSM8K 准确率

没有。四种方法全部低于基座，其中三种显著，自研方法与基座的差未达显著。

基座判对 794 条，即 0.6020。Full SFT 低 6.37 个百分点，LoRA 低 17.51 个百分点，P-Tuning v2 低 21.53 个百分点，三项的 Holm p 均小于 0.0001。降幅最小的是自研方法，低 2.12 个百分点，p 为 0.1226，故只能说没有测出差别，不能说二者相当，更不能说微调提高了准确率。

这个结果在开发集上独立出现。开发集 747 条，基座判对 490 条，即 0.6560。四种方法依次为 404、368、322 与 463 条，最高者为自研方法的 0.6198，仍低 27 条。开发集没有参与训练，所以测试集上的下降不是某一次划分的偶然。

原因有三条线索。

第一，基座本身已经很强。0.6020 对于一个 0.6B 模型偏高，GSM8K 测试集很可能在预训练阶段被收录过。若确实如此，微调能提升的空间本就很窄，而且微调会覆盖基座已经记住的题目模式。这一点无法从现有数据中分离，只能作为局限列出。

第二，训练目标比评测要求窄。训练时把 `<<...>>` 计算标注剥掉，只留答案正文，训练文本平均 186.8 token，最长 479 token。GSM8K 的生成均长从基座的 208.4 掉到 92.8 至 106.9，说明模型学到的是简短作答，中间的推理步骤被压缩甚至省略。长度与准确率在五个点上同序，自研方法保留的长度最多，准确率也最高。相关不等于因果，但这条线索与读数一致。

第三，训练题与测试题的分布不完全相同，这点没有单独做对照，只能作为待查方向。

## 4.2 不同方法之间的差异

先看最干净的一对比较。自研方法与 LoRA 的底座逐项相同，只多一项 KL 正则，所以两者之差可以直接归给这一项。GSM8K 上自研方法高 15.39 个百分点，即多判对 203 条，p 小于 0.0001；ARC 上低 1.62 个百分点，p 为 0.6839，不显著。也就是说，KL 项在通用域上没有测出代价的情况下把领域读数拉回了大半。

这个增益与输出长度同时恢复。LoRA 的生成均长为 106.9，自研方法为 184.5，接近基座的 208.4。可以理解为 KL 项主要阻止模型把作答分布收缩到过短的形态，而不是直接教它做题。

Full SFT 比 LoRA 高 11.14 个百分点，p 小于 0.0001。在 318 步的预算下全参微调仍占优，可能是 LoRA 的低秩容量限制，但实验没有做容量对照，不能把差值单独归因于 rank。

P-Tuning v2 在 GSM8K 与 ARC 上都显著低于其余三种方法。它的可训练量只有 1,146,880，约为 LoRA 的一半，前缀方法的优化难度也更高，两项都可能参与，现有设计分不开。

ARC 上 LoRA 的准确率最高，0.5725，比 Full SFT 高 0.77 个百分点，即 9 条，p 为 1.0000，不显著。而且两者的截断率分别是 0.2372 与 0.2517，都伴随明显的输出退化，不能把 LoRA 的读数读成通用能力更强。

## 4.3 ARC-Challenge 是否下降

按 v3 口径，ARC 上没有出现统一的准确率下降。Full SFT、LoRA 与自研方法显著高于基座，差值依次为 4.44、5.20 与 3.58 个百分点；P-Tuning v2 低 0.26 个百分点，与基座无显著差异。若就此断言微调提升了通用能力，与输出行为矛盾，所以要两套口径与行为指标一起看。

抽取口径对这一列的影响集中在 LoRA。v2 口径下 LoRA 判对 482 条，低于基座；v3 口径下判对 671 条，高于基座。差额 189 条全部来自 v3 新增的两级，这两级接住的是冗长输出里的正确选项正文。也就是说，LoRA 的准确率提升主要来自测量方式的改变，而不是模型新获得了推理能力。其余三种方法对口径不敏感，Full SFT 相差 10 条，自研方法相差 5 条，P-Tuning v2 相差 2 条，符号在两套口径下不变。

自研方法相对基座的正差值在 v2 下为 3.07 个百分点，在 v3 下为 3.58 个百分点，两套口径下都稳定且方向一致。这个稳定性使它的正差值比 LoRA 更可信，但幅度不大，ARC 的随机猜测期望是 0.2502，0.55 左右仍属中低水平，不宜过度解释。

行为指标给出更一致的遗忘信号。基座平均 12.7 token 就输出一个标签，Full SFT 与 LoRA 分别涨到 183.2 与 158.0 token，25.17% 与 23.72% 的样本写满 512 token 被截断，说明它们不再遵守只输出标签的指令。P-Tuning v2 的输出很短，均长 23.7，截断率与抽取失败率也低，但其两列准确率最低，它的退化落在目标领域而非输出形态。自研方法的三项指标都接近基座，截断率 0.0009，抽取失败率 0.0017。

结论是 ARC 的准确率没有统一下降，但四种方法在输出行为或目标领域读数上都退化了。遗忘体现在行为与格式上，而不是每个方法都掉准确率。这也是本实验不把 ARC 准确率单独当作遗忘指标的原因。

## 4.4 为什么出现灾难性遗忘

第一条是参数漂移。微调让模型离开基座参数点，去拟合 GSM8K 的分布，原来覆盖通用知识的输出分布被覆盖。四种方法都离开了基座，只是可改动的参数范围不同，所以退化的形态不同。系数扫描给出这一条的直接证据，系数越大，模型越靠近基座，目标领域读数越低，生成均长越接近基座的 208.4。

第二条是训练目标窄化。训练文本只含 GSM8K 的短答案与去掉标注的推理，平均 186.8 token，模型随之学会简洁作答。GSM8K 生成均长从 208.4 降到 92.8 至 106.9，ARC 上也出现指令不遵从。

第三条是格式遵循能力退化。选择题的作答约束是最容易被覆盖的一类行为。Full SFT 与 LoRA 输出极长并被截断，P-Tuning v2 的输出短却没有稳定复现标签形态，两类都说明模型没有保持基座的作答格式，只是失效方式不同。

第四条是数据污染。基座在 GSM8K 测试集上已有 0.6020，开发集 0.6560，偏高。若测试集在预训练时被收录，微调的可提升空间被压缩，读数下降里也有一部分是在覆盖已经记住的题目模式。

困惑度给出另一个侧面，但重训后的读数尚待测量。旧检查点上 LoRA 与自研方法的困惑度低于基座，Full SFT 略高，P-Tuning v2 高出近一个数量级。P-Tuning v2 的异常值来自前缀与无模板语料的分布不匹配，读数只作描述。该结论在重测回填前不作为本节依据。

四项指标合起来看，没有任何一种方法在全部维度上同向退化。LoRA 的 GSM8K 降幅大，Full SFT 的 GSM8K 降幅较小但 ARC 输出退化严重，P-Tuning v2 在两列准确率上最差，自研方法在两个数据集上都接近基座且行为指标最稳。所以遗忘是多维的，不能用一个指标排序。

## 4.5 如何缓解灾难性遗忘

本实验实际验证的缓解手段是 KL 正则。它以 15.39 个百分点的幅度在 GSM8K 上挽回了 LoRA 的损失，把 ARC 截断率降到 0.0009，生成均长恢复到 26.5，与基座几乎一致。

但它有边界。GSM8K 仍比基座低 2.12 个百分点，ARC 准确率也不高于 LoRA。所以 KL 项缓解的是输出格式退化与目标领域的部分损失，不能把领域读数拉回基座，也没有证据表明它改善了通用准确率。

系数 1.6 不是开发集最优点。0.8 档判对 243 条，1.6 档 241 条，相差 2 条，按预登记准则取较大系数。报告里不能把 1.6 写成调参得到的最优值。

没有测试的缓解手段包括数据混合与回放、早停、降低 rank、扩大适配器容量。这些只作为后续方向，不作为本实验的结论。

## 4.6 与已有工作的对照

LoRA 原论文的主要论点是，低秩更新在多个下游任务上可以接近全参微调，同时把可训练参数降到千分之一量级。本实验的 LoRA 可训练参数占 0.38%，GSM8K 上比全参微调低 11.14 个百分点，方向上与之一致，即参数高效方法并未完全追平全参微调，但差距不大。

P-Tuning v2 原论文报告在小模型上也能接近全参微调。本实验没有复现这一结论，P-Tuning v2 在 GSM8K 与 ARC 上都最低。一个可能的原因是任务与训练预算不同，本实验只有 318 步，前缀类方法通常需要更多步数才能收敛；另一个原因是前缀与输入模板强绑定，本实验的评测输入格式固定，训练与评测一致，这一点并未违反原则。两种解释都未做对照。

灾难性遗忘方面，EWC 一类方法通过对重要参数加约束来保留旧能力，本实验的 KL 正则与知识蒸馏的思路更接近，即在输出层面约束新模型靠近旧模型。结果说明输出层面的约束对格式与长度这类行为有效，但对准确率本身的恢复有限。

## 4.7 局限

1. 单种子。四种方法各训练一次，没有做多种子重复，方法间差异的抽样波动只由配对检验刻画，不含训练随机性。
2. 抽取规则敏感性。ARC 的结论依赖 v2 与 v3 两套口径，主表取 v3，v2 并列，两者对 LoRA 给出相反符号。
3. 基座污染。GSM8K 测试集可能被预训练收录，绝对准确率与提升空间都受影响。
4. 开发集与重训的时序。9 比 1 划分为 2026-11-11 的变更，原 400 条完整保留，补抽的 347 条曾出现在旧划分的训练与扫描中，故开发集整体不是从未被任何模型见过，但正式训练的四种方法均未见过其中任何一条。
5. 困惑度语料可能与预训练重叠，绝对值不与文献对照。重训后的困惑度尚待重测，重测前的读数不与本节的准确率并列。
6. ARC 难度。基座 0.5205，随机期望 0.2502，读数处于中低区间，小幅差异的实际意义有限。
