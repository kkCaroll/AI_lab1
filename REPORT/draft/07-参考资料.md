## 7.5 说明

课程说明所列的相关论文为 Cobbe 等、Hu 等与 Liu 等三篇，分别对应数据集、LoRA 与 P-Tuning v2，已列入第 3、7、8 条。其余条目为实验实际引用，包括基座模型报告、ARC 数据集、软提示的早期工作、灾难性遗忘与知识蒸馏、两项统计方法的原始文献，以及所用工具与平台。

课程说明另列的 TRL 与 LLaMA-Factory 两个训练框架本实验未使用，训练入口与四个方法模块自行实现，只依赖 transformers 与 peft，故不列入。实验二的 MATH-500、百炼平台、AutoGen 与 CrewAI 与本实验无关，同样不列入。
