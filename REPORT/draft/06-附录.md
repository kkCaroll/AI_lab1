# 附录

## A.1 代码结构

```text
exp1/
├── src/
│   ├── config.py          配置文件加载与校验，键路径覆盖
│   ├── data.py            数据加载、prompt 模板、训练目标文本
│   ├── extract.py         答案抽取级联，GSM8K 数值与 ARC 标签
│   ├── eval.py            统一评测入口，批量生成与指标汇总
│   ├── train.py           统一训练入口，训练循环与检查点
│   ├── utils.py           三态报告、种子、精度、显存统计
│   └── methods/
│       ├── sft.py         全参微调
│       ├── lora.py        LoRA 适配器
│       ├── ptuning.py     P-Tuning v2 前缀
│       └── custom.py      KL 正则化 LoRA
├── configs/
│   ├── base.yaml          公共配置
│   ├── full_sft.yaml      方法配置，另有 lora、ptuning、custom
│   ├── dev_split.json     400 条开发集索引
│   └── formal_runs.json   正式运行的配置与产物对照
├── scripts/
│   ├── prepare_data.py    数据下载与格式转换
│   ├── make_dev_split.py  开发集划分
│   ├── run_train.sh       训练启动脚本
│   ├── run_eval.sh        评测启动脚本
│   ├── run_ppl.sh         困惑度启动脚本
│   ├── analyze_results.py 区间、配对检验与行为指标
│   ├── measure_ppl.py     通用文本困惑度
│   ├── measure_lengths.py 训练文本长度统计
│   ├── reextract.py       离线重算抽取
│   └── export_tables.py   生成报告表格与图
└── tests/                 十个测试文件，208 项
```

四个方法模块都向训练入口注册同一套接口，即构造模型与优化器、取可训练参数、保存与加载适配器。训练入口不认识具体方法，方法之间也不互相依赖，所以新增一种方法只需加一个模块与一份配置。

## A.2 复现步骤

环境为 Python 3.12、torch、transformers 5.19.0、peft 0.21.2，数据与基座权重预置于 OSS。

训练，方法由配置文件给出。

```bash
cd exp1
CONFIG=configs/lora.yaml OUTPUT_DIR=/mnt/data/exp1/runs/R2-2 bash scripts/run_train.sh
```

评测，不带适配器时测基座。

```bash
OUTPUT_DIR=/mnt/data/exp1/runs/R2-2-eval ADAPTER=/mnt/data/exp1/runs/R2-2/adapter bash scripts/run_eval.sh
```

统计与制表。

```bash
python -m scripts.analyze_results
python -m scripts.export_tables
```

单元测试不需要 GPU，也不加载模型。

```bash
python -m pytest tests
```

## A.3 结果文件位置

| 路径 | 内容 |
| --- | --- |
| `RECORD/00-结果表.md` | 五方法两数据集的读数与现象记录 |
| `RECORD/01-实验配置.md` | 超参、方法特有参数、评测配置 |
| `RECORD/02-环境信息.md` | 平台、版本、任务台账与计量时长 |
| `runs/<任务编号>/` | 逐条预测、指标、配置快照与适配器 |
| `runs/analysis/summary.json` | 区间、配对检验与行为指标汇总 |
| `运行输出日志/` | 各次 DLC 任务的原始控制台输出 |

逐条预测为评测入口的原始产物，指标与表格都由它派生，报告中的每个数值可以回溯到某一份预测文件或某一份任务日志。
