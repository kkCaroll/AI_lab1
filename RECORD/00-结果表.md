# 实验一 结果表

本表为实验的核心产出，数据须与 `predictions.jsonl` 中的逐条记录一致。每行填写后注明运行标识，便于回溯到 `RECORD/01-实验配置.md`。

## 一 主结果表

训练与评测完成后填写。

| 方法 | GSM8K Accuracy | ARC-Challenge Accuracy | 运行标识 |
| --- | --- | --- | --- |
| Base Model | 0.6020 | 0.5205 | R2-13 与 R2-14 |
| Full SFT | 0.5125 | 0.5444 | R2-13 与 R2-14 |
| LoRA | 0.4435 | 0.5734 | R2-15 |
| P-Tuning v2 | 0.3829 | 0.4991 | R2-15 |
| 自研方法 | 0.5701 | 0.5546 | R3-7 |

Base Model 一行取同一机型上的重评读数，即 R2-13 的 GSM8K 794/1319 与 R2-14 的 ARC 610/1172，使基线与三种方法处于同一硬件与同一精度。R1-1 在 V100 上的读数为 GSM8K 0.6035 与 ARC 0.5205，两个 GSM8K 读数相差 2 条样本，低于一个标准误，故替换不改变任何结论，原读数保留作硬件间的一致性核对。ARC 列的前四种方法读数由本机按 v3 抽取规则离线重算，生成侧未重跑，原先判对的样本无一条改动，理由见 `RECORD/01-实验配置.md` 第五节。v2 严格口径下的 ARC 读数为 0.5205、0.5290、0.4642、0.3805 与 0.5512，依次为 M0 至 M4，列为稳健性对照，不入主表。自研方法的 ARC 读数由 R3-7 在 v3 下直接评测取得，抽取失败 3 条；其 v2 严格口径由同一份已落盘的逐条预测离线回算，判对 646 条，抽取失败 9 条，与 v3 相差 4 条即 0.34 个百分点，不足一个标准误。自研方法相对基线的两项差值为 GSM8K 低 42 条即 3.18 个百分点，ARC 高 40 条即 3.41 个百分点，按两独立比例的差值标准误折算各约 1.7 倍，均未达两个标准误。同批样本的 McNemar 精确检验利用了两次判断的相关性，两项在 Holm 校正后分别为 p 等于 0.0166 与 0.0218，均判为显著，完整结果见 `RECORD/03-统计分析与配对检验.md`。两法结论不同的原因是配对检验只计入判断不一致的样本，功效更高，报告以配对检验为准，独立比例的标准误保留作量级参照。

## 三 补充表

补充表用于支撑结果分析，非任务书要求，可在报告中选择性呈现。

| 方法 | GSM8K 95% 置信区间 | ARC 95% 置信区间 | 通用文本困惑度 |
| --- | --- | --- | --- |
| Base Model | 0.5753 至 0.6281 | 0.4919 至 0.5490 | 24.34 |
| Full SFT | 0.4855 至 0.5394 | 0.5158 至 0.5727 | 27.67 |
| LoRA | 0.4169 至 0.4705 | 0.5449 至 0.6014 | 22.27 |
| P-Tuning v2 | 0.3570 至 0.4094 | 0.4706 至 0.5277 | 229.43 |
| 自研方法 | 0.5432 至 0.5966 | 0.5260 至 0.5828 | 23.18 |

五行区间由主结果表的准确率与样本数按 Wilson 得分法算出，ARC 侧取实际准确率而非随机猜测水平。Base Model 一行原先按正态近似算出的 0.5756 至 0.6284 与 0.4919 至 0.5491 已由本次结果替换，差别在小数第三位。

困惑度取 R4-1 任务，语料为 WikiText-2 train 的前 2,000,000 个 token，按 1,953 个不重叠的 1024 token 窗口计分，计分 token 1,997,919，五个模型同取 float16。相对基座的比值为 Full SFT 1.137、LoRA 0.915、P-Tuning v2 9.426、自研方法 0.952。P-Tuning v2 的读数高出基座近一个数量级，其前缀训练时只见过对话模板格式的 GSM8K 输入，而困惑度语料为无模板的原始文本，前缀与输入分布不匹配，故该值不能单独读作通用语言知识的损失，须与 ARC 抽取失败率 0.0904 并列解释。LoRA 与自研方法在该语料与协议下低于基座，未见通用语言建模退化，遗忘主要表现于任务准确率与输出行为。

## 四 配对比较

对同一批测试样本做配对检验，用于判断方法间差异是否超出抽样误差。差值为前者减后者，单位为百分点。p 为 McNemar 精确检验双侧值，经同一数据集同一家族内的 Holm 校正，小于 0.05 判为显著。完整十对见 `RECORD/03-统计分析与配对检验.md`。

| 对比 | GSM8K 差值 pp | GSM8K Holm p | ARC 差值 pp | ARC Holm p |
| --- | --- | --- | --- | --- |
| Full SFT 与 Base | -8.95 | <0.0001 | +2.39 | 0.3319 |
| LoRA 与 Base | -15.85 | <0.0001 | +5.29 | 0.0012 |
| P-Tuning v2 与 Base | -21.91 | <0.0001 | -2.13 | 0.3319 |
| 自研方法与 Base | -3.18 | 0.0166 | +3.41 | 0.0218 |
| 自研方法与 LoRA | +12.66 | <0.0001 | -1.88 | 0.3357 |
| 自研方法与 Full SFT | +5.76 | 0.0003 | +1.02 | 0.5675 |
| 自研方法与 P-Tuning v2 | +18.73 | <0.0001 | +5.55 | 0.0032 |

GSM8K 上四种微调方法均显著低于基线，自研方法的降幅最小，且显著高于另三种方法；LoRA 显著低于 Full SFT，P-Tuning v2 显著低于另三种。ARC 上 LoRA 与自研方法显著高于基线，Full SFT 与 P-Tuning v2 相对基线无显著差异；自研方法与 LoRA 的差值不显著，与 Full SFT 的差值亦不显著，与 P-Tuning v2 的差值显著为正。
