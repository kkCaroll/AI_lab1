# 实验一 结果表

本表为实验的核心产出，数值与 `exp1/runs/analysis/summary.json` 及 `RECORD/03-统计分析与配对检验.md` 一致。全部读数取 2026-11-11 完成的 P6-1 任务，数据划分按课程要求改为 9 比 1，训练集 6726 条、开发集 747 条。划分变更与重训理由见 `RECORD/01-实验配置.md` 第六节。

## 一 主结果表

| 方法 | GSM8K Accuracy | ARC-Challenge Accuracy | 运行标识 |
| --- | --- | --- | --- |
| Base Model | 0.6020 | 0.5205 | R2-13 与 R2-14，开发集取 P6-1 |
| Full SFT | 0.5383 | 0.5648 | P6-1 |
| LoRA | 0.4268 | 0.5725 | P6-1 |
| P-Tuning v2 | 0.3867 | 0.5179 | P6-1 |
| 自研方法 | 0.5807 | 0.5563 | P6-1 |

Base Model 一行取同一机型上的重评读数，即 R2-13 的 GSM8K 794/1319 与 R2-14 的 ARC 610/1172，使基线与四种方法处于同一硬件与同一精度。基座未参与重训，其测试集读数不随划分变更而变，开发集读数则由 P6-1 在 747 条上重评得到。

四种方法的测试集读数由 P6-1 一次取得，生成侧即按 v3 抽取规则运行，不再经过离线重算。GSM8K 判对条数为 710、563、510 与 766，ARC 判对条数为 662、671、607 与 652，依次为 M1 至 M4。

GSM8K 上基座 0.6020 仍为最高。三种方法显著低于基座，即 Full SFT 低 6.37 个百分点、LoRA 低 17.51 个百分点、P-Tuning v2 低 21.53 个百分点；自研方法低 2.12 个百分点，Holm 校正后 p 为 0.1226，未达显著，故其与基座的高低不能由本批样本判定。自研方法显著高于另三种方法，其中与 LoRA 的差为 15.39 个百分点，与 Full SFT 的差为 4.25 个百分点，与 P-Tuning v2 的差为 19.41 个百分点。

ARC 上 LoRA 与 Full SFT 显著高于基座，差值为 5.20 与 4.44 个百分点；自研方法高 3.58 个百分点，Holm 校正后 p 为 0.0137，亦达显著；P-Tuning v2 低 0.26 个百分点，p 为 0.9094，不显著。自研方法与 LoRA 相差 1.62 个百分点，与 Full SFT 相差 0.85 个百分点，两者均不显著；与 P-Tuning v2 的差为 3.84 个百分点，显著。

开发集 747 条的读数为基座 490 条即 0.6560、Full SFT 404 条即 0.5408、LoRA 368 条即 0.4926、P-Tuning v2 322 条即 0.4311、自研方法 463 条即 0.6198。该开发集只用于选择超参，未进入任何一次正式训练。在准确率 0.55 至 0.66 的区间内，747 条的二项标准误约为 1.7 至 1.8 个百分点，小于此数的两法差异不判为有别。

## 四 配对比较

对同一批测试样本做配对检验，用于判断方法间差异是否超出抽样误差。差值为前者减后者，单位为百分点。p 为 McNemar 精确检验双侧值，经同一数据集同一家族内的 Holm 校正，小于 0.05 判为显著。完整十对见 `RECORD/03-统计分析与配对检验.md`。

| 对比 | GSM8K 差值 pp | GSM8K Holm p | ARC 差值 pp | ARC Holm p |
| --- | --- | --- | --- | --- |
| Full SFT 与 Base | -6.37 | <0.0001 | +4.44 | 0.0137 |
| LoRA 与 Base | -17.51 | <0.0001 | +5.20 | 0.0017 |
| P-Tuning v2 与 Base | -21.53 | <0.0001 | -0.26 | 0.9094 |
| 自研方法与 Base | -2.12 | 0.1226 | +3.58 | 0.0137 |
| 自研方法与 LoRA | +15.39 | <0.0001 | -1.62 | 0.6839 |
| 自研方法与 Full SFT | +4.25 | 0.0061 | -0.85 | 1.0000 |
| 自研方法与 P-Tuning v2 | +19.41 | <0.0001 | +3.84 | 0.0262 |

GSM8K 上三种方法显著低于基线，自研方法与基线的差为负而未达显著，且显著高于另三种方法。LoRA 显著低于 Full SFT，P-Tuning v2 显著低于另三种。ARC 上 Full SFT、LoRA 与自研方法显著高于基线，P-Tuning v2 相对基线无显著差异；自研方法与 LoRA、与 Full SFT 的差均不显著，与 P-Tuning v2 的差显著为正。

## 五 现象记录

记录与预期不符的观察。抽取失败样例、输出格式异常、训练损失不收敛等现象均记于此，供结果分析引用。

| 现象 | 涉及方法 | 出现规模 | 初步判断 |
| --- | --- | --- | --- |
| ARC 抽取规则 v1 在末位级误取正文末字母 | Base Model | 降级 39 条与失败 45 条 | 模型多以标签点号接选项正文作答，短输出的末位是正文末字母如 F 与 s，既不在本题标签集合内又中止了级联。v2 改为只认本题标签并下沉，84 条中 83 条接住，余 1 条是截断的长解释文本 |
| GSM8K 训练目标格式未迁移 | Base Model | 828 条含盒式值，491 条使用 `####` 标记 | 基座未经指令微调，标记命中率 0.3722，主要抽取量落在引导语级 820 条。末值兜底 8 条全部判错，与截断及跑偏样本重合 |
| ARC 抽取级联未覆盖微调后的两种作答形态 | Full SFT、LoRA、P-Tuning v2 | v3 下抽取失败依次为 70、38、5 条；v2 口径下为 97、364、11 条 | 一类为标签与正文之间只有空格而无标号，另一类为选项正文之前多出描述性成分，原四级级联均不命中。v3 追加无标点标签与全文正文查找两级后，LoRA 侧接住 326 条并判对 189 条，为四种方法中最大的一处口径差 |
| LoRA 在 ARC 上的两套口径给出相反符号 | LoRA | v2 判对 482 条低于基座 128 条，v3 判对 671 条高于基座 61 条 | 差额来自冗长输出中的正确选项正文被 v3 的两级读出，不表示模型新获得推理能力。该列的解读须与截断率 0.2372 并列，结论以行为指标为准 |
| ARC 输出极长并触到上限 | Full SFT、LoRA | 截断 295 与 278 条，截断率 0.2517 与 0.2372 | 二者在 ARC 上的生成均长为 183.2 与 158.0 token，而基座为 12.7 token。只输出标签的指令未被保持，属格式层面的遗忘 |
| ARC 输出短但不带标签 | P-Tuning v2 | 抽取失败 5 条，均长 23.7 token | 前缀方法保留了短输出，却未稳定复现标签形态，与 GSM8K 上的 0.4311 同向 |
| Markdown 粗体标签导致抽取失败 | 自研方法 | 2 条 | 模型把标签与正文一并加粗，如 `**C. 50%**`，级联各级假设标签前后为空白或标点。2 条中 1 条本可判对，故 ARC 准确率至多低估 0.09 个百分点 |
