# 实验一 四个分析问题的回答

本文件为报告正文的要点草稿。数值一律取 `RECORD/03-统计分析与配对检验.md`，显著性以同数据集同家族 Holm 校正后的 McNemar 精确检验为准，行为指标取该文件第二节。差值为前者减后者，单位为百分点。

## 一 微调是否提高了 GSM8K 准确率

结论是没有。四种微调方法在 1319 条测试样本上均显著低于基座，降幅最小的是自研方法，仍低 3.18 个百分点。

| 对比 | 差值 | 配对差值 95% 区间 | Holm p | 判定 |
| --- | --- | --- | --- | --- |
| Full SFT 与 Base Model | -8.95 | -11.84 至 -6.05 | 小于 0.0001 | 显著 |
| LoRA 与 Base Model | -15.85 | -18.76 至 -12.93 | 小于 0.0001 | 显著 |
| P-Tuning v2 与 Base Model | -21.91 | -24.89 至 -18.93 | 小于 0.0001 | 显著 |
| 自研方法与 Base Model | -3.18 | -5.73 至 -0.64 | 0.0166 | 显著 |

同一现象在开发集上独立出现。400 条开发集上基座判对 254 条即 0.6350，截至 2026-10-16 的三十四个微调读数最高为 210 条即 0.5250，低 44 条。开发集只用于选择超参，未参与训练，故测试集上的下降不能归因于某一次划分的偶然。

输出长度与准确率同向变化，是解释这一结果的主要线索，但相关本身不构成因果。GSM8K 生成均长在基座为 208.4 token，Full SFT 降至 93.5，LoRA 降至 108.7，P-Tuning v2 降至 110.0，自研方法为 185.9。训练目标剥离了 `<<...>>` 计算标注，只保留较短的答案正文，一种可能是模型学到简短作答并逐步省略中间推理。自研方法保留的长度最多，准确率也最高，两者在五个点上同序，与该解释一致，但尚不能排除长度与准确率同受第三个因素影响。

基座读数偏高另有一项不能排除的原因。Qwen3-0.6B 在 GSM8K 测试集上达到 0.6020，对同规模模型偏高，测试集可能在预训练阶段被收录，即风险 R9。若属实，微调的可提升空间本就被压缩，且微调会覆盖基座已经记住的题目模式。该项无法从现有数据分离，只能作为局限披露。

## 二 不同方法之间的差异

核心对比是自研方法与 LoRA。两者共享同一 LoRA 底座，rank、alpha、dropout、目标模块、学习率、轮数、批大小与随机种子逐项相同，唯一差别是损失中多一项系数为 1.6 的 KL 正则。因此两者之差可直接归因于 KL 项。

| 对比 | GSM8K 差值 | GSM8K Holm p | ARC 差值 | ARC Holm p |
| --- | --- | --- | --- | --- |
| 自研方法与 LoRA | +12.66 | 小于 0.0001 | -1.88 | 0.3357 |
| 自研方法与 Full SFT | +5.76 | 0.0003 | +1.02 | 0.5675 |
| 自研方法与 P-Tuning v2 | +18.73 | 小于 0.0001 | +5.55 | 0.0032 |

KL 项在目标领域挽回了 167 条样本，即 12.66 个百分点，并把生成均长由 108.7 拉回 185.9。这一增益与输出长度恢复同时发生，说明它主要阻止模型把作答分布收缩到过短的形态，而不是单纯提高某类题目的推理能力。ARC 上自研方法比 LoRA 低 22 条即 1.88 个百分点，配对检验不显著，故没有证据表明 KL 项损害了通用准确率。

其余方法间的差异同样显著，但不能只按方法类别排序。GSM8K 上 Full SFT 比 LoRA 高 6.90 个百分点，Holm p 小于 0.0001，在 333 步预算下全参微调仍占优，可能反映 LoRA 的低秩容量限制，但本实验未做容量对照，不能把该差值单独归因于 rank。P-Tuning v2 在 GSM8K 与 ARC 上均显著低于另三种方法，其可训练量仅 1,146,880，约为 LoRA 的一半，前缀微调的优化难度也更高，两项都可能参与，现有设计不能分离。ARC 上 LoRA 比 Full SFT 高 2.90 个百分点，但 Holm p 为 0.1747，不显著，且 Full SFT 的截断率为 0.4514，LoRA 为 0.2696，两者的准确率都伴随明显的输出退化，不能把 LoRA 的读数读作通用能力更强。

## 三 ARC-Challenge 是否下降

按 v3 抽取口径，ARC 上没有出现统一的准确率下降。LoRA 与自研方法显著高于基座，Full SFT 与 P-Tuning v2 相对基座不显著。若据此断言微调提升了通用能力，则与输出行为矛盾，故须并列 v2 口径与行为指标。

| 方法 | v2 判对 | v2 准确率 | v3 判对 | v3 准确率 | v3 减 v2 |
| --- | --- | --- | --- | --- | --- |
| Base Model | 610 | 0.5205 | 610 | 0.5205 | 0 |
| Full SFT | 620 | 0.5290 | 638 | 0.5444 | +18 |
| LoRA | 544 | 0.4642 | 672 | 0.5734 | +128 |
| P-Tuning v2 | 446 | 0.3805 | 585 | 0.4991 | +139 |
| 自研方法 | 646 | 0.5512 | 650 | 0.5546 | +4 |

LoRA 与 P-Tuning v2 的符号在两套口径间翻转。LoRA 在 v2 下低 66 条，在 v3 下高 62 条，差额 128 条全部来自 v3 新增的无标点标签与全文正文查找两级。这两级接住的是冗长输出中的正确选项正文，而不是模型新获得的推理能力。故 LoRA 在 v3 下的 0.5734 不能直接读作通用能力提升。

自研方法对口径不敏感，v3 仅比 v2 多 4 条，其相对基座的正差值在 v2 下为 36 条即 3.07 个百分点，在 v3 下为 40 条即 3.41 个百分点。这一稳定性使它的 ARC 正差值比 LoRA 更可信，但幅度不大，且 ARC 的随机猜测期望为 0.2502，0.55 左右仍属中低水平，不宜过度解释。

行为指标给出更一致的遗忘信号。

| 方法 | ARC 生成均长 | 截断率 | 抽取失败率 |
| --- | --- | --- | --- |
| Base Model | 12.7 | 0.0009 | 0.0000 |
| Full SFT | 279.7 | 0.4514 | 0.0768 |
| LoRA | 174.4 | 0.2696 | 0.0333 |
| P-Tuning v2 | 26.3 | 0.0034 | 0.0904 |
| 自研方法 | 23.6 | 0.0000 | 0.0026 |

Full SFT 与 LoRA 不再遵守只输出标签的指令，生成长度增至基座的十余倍，近半或近三成样本撞上 512 的上限。P-Tuning v2 的截断率很低，但近一成样本无法抽出标签，形态是短句作答不带标签。自研方法的三项指标均接近基座，其 3 条抽取失败来自 Markdown 粗体标签，已在 `LOG/02-问题与解决.md` Q22 记录。

通用文本困惑度提供第三个维度。基座为 24.34，Full SFT 为 27.67，LoRA 为 22.27，P-Tuning v2 为 229.43，自研方法为 23.18。LoRA 与自研方法低于基座，Full SFT 略高，P-Tuning v2 高出近一个数量级。P-Tuning v2 的异常值与前缀的训练分布有关，前缀只见过对话模板格式的 GSM8K 输入，而困惑度语料为无模板的原始文本，该值不能单独读作通用语言知识的损失。三项指标合起来看，没有任何一种方法在全部维度上同向退化。LoRA 的 GSM8K 降幅大而困惑度略降，Full SFT 的 GSM8K 降幅较小而困惑度上升，P-Tuning v2 在两项上均最差，自研方法在两项上均接近基座。故遗忘是多维的，不能以单一指标排序。

本文件的判据因此取准确率、输出行为与通用困惑度的联合口径。ARC 准确率不支持统一的灾难性遗忘，但四种方法均在某项行为指标上退化，自研方法退化最轻。v2 口径与 v3 口径并列报告，不以后者覆盖前者。

## 四 遗忘的成因与缓解

候选成因分四条，各配一项证据。

第一，参数漂移使基座分布被目标分布覆盖。四种方法都离开了基座参数点，KL 项系数越大，模型越靠近基座，目标领域读数越低。五档系数在开发集上的判对数为 196、195、243、241 与 233，生成均长随系数增大向基座的 208.4 靠拢，两者构成同一条权衡曲线。

第二，训练目标只含 GSM8K 的短答案与去标注推理，输出长度分布随之收缩。GSM8K 生成均长由 208.4 降至 93.5 至 110.0，降幅与准确率降幅同序，是最直接的一条证据。训练文本平均 186.8 token，最长 479 token，本身即短于基座的自由作答。

第三，选择题的格式遵循能力随微调退化。ARC 生成均长在 Full SFT 与 LoRA 上分别增至 279.7 与 174.4，截断率为 0.4514 与 0.2696。P-Tuning v2 走向另一极端，输出很短但不带标签，抽取失败率为 0.0904，其困惑度 229.43 进一步说明前缀在无模板文本上失配。两类形态都说明模型未保持基座的作答约束。

第四，基座在 GSM8K 测试集上可能已有污染，可提升空间被压缩。基座测试集 0.6020、开发集 0.6350，对 0.6B 模型偏高，见风险 R9。该项不能由现有数据消除，只能作为局限说明。

缓解以 KL 正则为主。它在 GSM8K 上比 LoRA 高 12.66 个百分点，把 ARC 截断率降至零，生成均长回到 23.6。但它没有把 GSM8K 拉回基座，仍低 3.18 个百分点，ARC 准确率也不高于 LoRA。困惑度上自研方法为 23.18，低于基座的 24.34，略高于 LoRA 的 22.27，说明 KL 项没有把原始文本的语言建模拉回或超过 LoRA。故 KL 项缓解的是目标领域退化与输出格式退化，不保证通用准确率或困惑度同步改善。

系数 1.6 不是开发集最优点。0.8 档判对 243 条，1.6 档判对 241 条，相差 2 条即 0.2 个标准误，按预登记准则取较大系数。报告须写明这一点，不能把 1.6 写成调参得到的最优值。

未测试的缓解手段包括数据混合与回放、早停、降低 rank、扩大适配器容量。这些只作为后续方向，不作为本实验的结论。

## 五 局限

1. 单种子。四种方法各训练一次，未做多种子重复，方法间差异的抽样波动只由配对检验刻画，不含训练随机性。
2. 抽取规则敏感性。ARC 结论依赖 v2 与 v3 两套口径，主表取 v3，v2 并列，二者对 LoRA 与 P-Tuning v2 给出相反符号。
3. 基座污染。GSM8K 测试集可能被预训练收录，绝对准确率与提升空间均受影响。
4. 硬件换机。前段为 V100，2026-10-17 起为 A10，正式读数全部取 A10 与 float16，方法间可比，但与此前开发集读数跨硬件。
5. 通用文本困惑度已测，语料取 WikiText-2 train 的前二百万 token，存在预训练重叠，绝对值不与文献对照。P-Tuning v2 的前缀在该语料上分布不匹配，其读数只作描述，不参与方法排序。
6. ARC 难度与天花板。基座 0.5205，随机期望 0.2502，读数处于中低区间，小幅差异的实际意义有限。
