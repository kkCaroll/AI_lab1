# M4 方案说明

本文件是 P3.1 的产出，记录自研方法的选定依据、形式定义、资源代价与超参选择方式。实现见 `exp1/src/methods/custom.py`，配置见 `exp1/configs/custom.yaml`。

## 一 选定依据

P2 的结果定了两件事。

其一，三种方法在 GSM8K 测试集上均低于 M0，读数依次为 0.5125、0.4435 与 0.3829，基线为 0.6020。目标域的倒退使 M4 不能只追准确率，还要避免把原有行为一并改掉。

其二，遗忘的可见形态是输出退化。ARC 上的截断率为 0.4514、0.2696 与 0.0034，抽取失败率为 0.0768、0.0333 与 0.0904，而 M0 两项为 0.0009 与 0。模型在未见过的题目上改写出长段推理并陷入循环，准确率的涨跌有一部分被抽取规则吸收，故单看 ARC 准确率不足以为证。

据此 M4 的目标定为把输出分布拉回基座，同时尽量不牺牲目标域。风险清单 R6 限定的四类方案中，以基座输出做 KL 正则直接作用于输出分布，与上述目标对应，故选此类。降秩只改参数容量，P2 的 LoRA 训练损失在 0.58 附近走平而未见过拟合，压容量更可能压低目标域读数。参数约束一项因 LoRA 初值接近零，其作用接近强权重衰减。早停一项在 LoRA 的五轮读数上全距仅 9 条，收益难以分辨。

## 二 形式

记基座模型为冻结的参考分布 p_ref，当前策略为 p_θ，完成段为标签非 -100 的位置。M4 的训练目标为

    L = L_lm + β · KL(p_ref ‖ p_θ)

其中 KL 取每个完成位置上的全词表散度，按完成 token 数取均值。β 为系数，取值见第五节。

散度方向取基座在前的形式。该方向上梯度等于用基座的软标签做蒸馏，权重受基座概率约束，数值稳定。反向的散度在策略把概率放到基座近零的位置时会令对数项发散，训练早期策略偏离越大越显著，故不取。

完成段之外的位置不计入 KL。提示段五种方法共用同一文本，其漂移不直接对应遗忘，且语言建模损失本就掩掉提示段，两项取同一支撑集后 β 与交叉熵可直接比较量级。

参考模型在装配时由基座深拷贝得到，此时基座尚未挂载适配器，故参考分布恰为未经训练的原模型。参考模型置 float32、全参数不求梯度、恒为评测模式，且以旁路属性挂在适配器模型上而不经模块注册，因而不进入参数统计、不进入检查点、不进优化器。步数为零时策略与参考相同，散度自然为零，故不设预热。

## 三 与 M2 的关系

M4 的其余配置与 M2 逐项相同，即 LoRA 秩 8、alpha 16、dropout 0.05、四个注意力投影、学习率 1.0e-4、3 轮 333 步、微批 8、累积 8、梯度检查点开启、float16 计算路径。两法只差正则项一处，故读数之差可直接归给该项。

可训练参数与 M2 相同，为 2,293,760。参考模型不计入统计，故占比仍为 0.003834。

## 四 资源与工程约束

显存方面，参考模型常驻 2.38 GiB，逐批另跑一次前向并保留其输出，按 P2.6 实测的 LoRA 峰值 10.58 GiB 计，预计总量在 13 至 15 GiB 之间，A10 的 24 GiB 有余量。

算力方面，每步多一次无梯度的前向，约占原单步计算的三分之一。LoRA 的 29.2 分钟预计升至 38 至 42 分钟。

数值方面，词表为 151,936 行，两个模型的输出对同一批文本各为批大小乘序列长度乘词表数。若整段上转为 float32 再算散度，两份张量合计可达数 GiB，故沿序列维分块计算，每块上转一次，块宽取 128。

## 五 超参选择

β 在开发集上扫三点，取 0.05、0.2 与 0.8，按四倍跨度覆盖由弱到强三档。三臂一律 3 轮 333 步且共用基座配置，故与 M2 的调度一致。

选择准则与 P2 相同，即开发集正确数最高者胜，差值不足一个标准误时取较大的一档。取较大者的理由是该方法的目标是保持而非拟合，在读数不可分辨时应偏向正则更强的一侧。

ARC 不参与选择。R7 要求超参选择只依据开发集，故正则项在 ARC 上的收益在选择过程中不可见，该局限须在报告中披露。

2026-10-19 的首轮三臂读数为 196、195 与 243 条，随系数单调上升，最优落在范围上界且未见拐点。按 P2 两处边界情形的同一处理，向上扩一档至 1.6 与 3.2，其余配置与首轮三臂相同。

扩扫两臂于同日完成，开发集读数为 241 与 233 条，生成均长 180.7 与 191.7 token，末段每 token 散度分别为 0.0723 至 0.0924 与 0.0346 至 0.0450。曲线在 0.8 处转折，仍单调上升一支未触发。最高读数 243 条落在 0.8，1.6 与之相差 2 条即 0.2 个标准误，3.2 与之相差 10 条即 1.02 个标准误。按本节前定的准则，与最高值不可分辨者取较大系数，故系数定为 1.6。3.2 的差值已在一个标准误之外且低于 1.6，不取。该取舍由准则而非读数给出，报告中不得写作 1.6 在开发集上更优。

均长自 153.3 经 180.7 升至 191.7，向基线的 208.4 继续靠拢，末段散度随系数增大而降低并在数点内走平，说明系数决定的是策略与基座之间的平衡距离，而非把训练信号逐轮抹平。两项只作描述，不参与选择。

扩扫一段的原措辞为按取最早不可分辨点的准则定于 1.6。该句按 1.6 明显高于 0.8 的假想情形写成，与本节前文在同一数据上会给出相反取值。定案后改写为与主准则一致的表述，即以最高读数为基准，差值不足一个标准误者取较大系数，达一个标准误者不取。

## 六 验收与风险

R6 的数据约束由接口结构保证，方法模块只收到本方法配置段，无从读到数据集路径。参考模型取自同一基座，训练数据仍只有 GSM8K 训练集剔除开发集后的 7073 条。

数值上须核对两处。一是训练日志中的每 token 散度，其量级决定 β 的取值范围是否合适，若均值始终低于 0.01 或始终高于 2，则三点可能都落在有效区间之外，须改范围重扫。二是末轮散度是否随训练单调上升，若在数十步内锁定于零，说明参考模型未被正确冻结或未正确前向。

评测口径与另三法一致，上限 512、贪心解码、抽取规则 v3 入主表，v2 严格口径并列作稳健性对照。截断率与抽取失败率作为输出退化的行为指标一并报告，用以检验正则项是否压住了退化。

风险一项，若三臂的开发集读数均明显低于 M2 的 194 条，则说明在 0.05 处正则已过强，须向小值方向重扫。该项与 R21 的处置方式相同，即按读数判断范围是否覆盖有效区间，不把范围外的不收敛记为方法无效。
